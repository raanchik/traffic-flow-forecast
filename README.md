# Traffic Flow Forecast — прогнозирование интенсивности движения

Учебный Python-проект, восстановленный по листингу в приложении выпускной квалификационной работы (МАДИ, 2025): «Исследование методом кластерного анализа данных прогнозирования транспортного потока городской агломерации».

**Что делает:** читает временные ряды интенсивности движения из Excel/CSV; позволяет выбрать участок дороги в интерфейсе Flet; строит прогноз примерно на пять лет при помощи **Prophet**; визуализирует прогноз, его компоненты и сравнение с фактическими значениями с помощью Matplotlib.

> **Оговорка о методах:** в теоретических разделах ВКР рассматривается кластерный анализ, включая K-means, но опубликованный в приложении Python-листинг реализует прогнозирование через Prophet. Этот репозиторий воспроизводит именно реализованную часть, **не выдавая её за реализацию K-means**.

> **О данных:** `data/sample_traffic.csv` — **искусственно сгенерированные данные**, созданные только для демонстрации. Это не измерения на М-4 и не данные компании. Исходный файл `IntensV2.xlsx` из PDF в репозитории отсутствует; он не был приложен к дипломному PDF.

## Технологии

- Python 3.11 (рекомендуется)
- pandas для загрузки и подготовки данных
- Prophet для прогноза временного ряда
- Matplotlib для визуализации
- Flet 0.28.3 для графического интерфейса

## Быстрый запуск (Windows PowerShell)

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Если PowerShell блокирует `Activate.ps1`, можно обойти активацию:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Если Python 3.11 не установлен, установите его с [python.org](https://www.python.org/downloads/) или используйте уже установленную совместимую версию Python. Prophet при установке может скачивать дополнительные библиотеки/модельные компоненты.

В браузере откроется локальная программа. Выберите участок дороги и нажмите «Выполнить прогноз». Демо-данные позволяют проверить интерфейс без приватных файлов.

## Работа со своими данными

Можно подставить собственный CSV или Excel через переменную среды. Например:

```powershell
$env:TRAFFIC_DATA_FILE = "C:\\Data\\IntensV2.xlsx"
python app.py
```

Ожидаемый формат: столбец `Дата` (строки, распознаваемые как даты) и одна или несколько колонок интенсивности. Названия в исходном листинге:

```text
Интенсивностькм228
Интенсивностькм322
Интенсивностькм339
Интенсивность416
Интенсивностькм460
```

`Интенсивность416` приведено **ровно как в PDF**; если исходный Excel использует другое имя, его нужно сопоставить с кодом. Сырые данные, учетные записи и коммерческие выгрузки публиковать не следует. В `.gitignore` исходные Excel-файлы и сторонние файлы из `data/` исключены.

## Происхождение

Исходный листинг: **приложение диплома, страницы PDF 89–93**. Дополнительные фрагменты обработки ошибок приведены на стр. 50–51. PDF содержит не программные файлы, а текст, разорванный переносами страниц и редакторским форматированием, поэтому источники были **реконструированы вручную**, а не извлечены побайтово.

## Что важно для портфолио

Это учебный прототип, а не промышленный сервис прогноза трафика. В нём не приведены оценки качества по отложенной выборке (MAE/RMSE/MAPE), нет выделенной реализации K-means, и исходные корпоративные измерения не входят в публикацию. Для следующей версии имеет смысл добавить проверку прогноза на истории, сравнение с наивным baseline и скриншоты интерфейса после локального запуска.
